# SmartPark

## Parking Management System

SmartPark is a Java-based Parking Management System developed as part of an Object-Oriented Programming coursework project.

The system aims to provide an organized and user-friendly solution for managing parking operations through a graphical desktop application.

## Technologies

- Java 26
- Java Swing
- Apache Maven
- Git
- GitHub
- MySQL (planned/optional)
